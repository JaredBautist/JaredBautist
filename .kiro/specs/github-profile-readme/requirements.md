# GitHub Profile README Requirements

## Purpose

Create a concise, credible GitHub profile for Jared Bautista that communicates his
engineering focus, demonstrated technologies, strongest public projects, and
professional impact.

## Acceptance Criteria

1. WHEN a visitor opens `github.com/JaredBautist`, the profile SHALL identify
   Jared as a full-stack software engineer based in Colombia and summarize his
   focus on backend, cloud, AI-assisted development, and clean architecture.
2. WHEN the technology section is displayed, the profile SHALL group the stack
   by engineering concern instead of presenting an unstructured badge wall.
3. WHEN featured projects are displayed, the profile SHALL rank AXOLOT first,
   Coworking Management Platform second, and the MIPRES platform third.
4. WHEN a featured project is described, the profile SHALL link to its public
   repository and use technologies and capabilities supported by that repository.
5. WHEN professional impact is presented, the profile SHALL include healthcare
   automation and the user-provided PrimeWorks Top 2 finalist achievement without
   inventing unverifiable metrics.
6. WHEN a visitor uses light or dark GitHub themes, the content SHALL remain
   readable and shall not depend on color alone to communicate meaning.
7. WHEN contact options are displayed, every published option SHALL be actionable;
   unknown LinkedIn and email values SHALL not appear as broken placeholders.
8. WHEN the change is complete, the repository SHALL be public, named exactly
   `JaredBautist/JaredBautist`, and the README SHALL be pushed to its default branch.
9. WHEN the profile header loads, it SHALL present Jared's name and engineering
   positioning with subtle animation inspired by the supplied dark portfolio
   reference.
10. WHEN a visitor prefers reduced motion, the animated header SHALL render as a
    stable composition without continuous movement.
11. WHEN professional details are displayed, the profile SHALL state Spanish as
    Jared's native language and English proficiency as C1.
12. WHEN profile content is displayed, all professional copy SHALL be written in
    English.
13. WHEN AI development tools are displayed, the profile SHALL show recognizable
    logos for Claude Code, Codex, Antigravity, and Kiro in one centered icon row that
    matches the visual rhythm of the technology stack, with each logo linking to its
    official product page and exposing a descriptive accessible name.

## Out of Scope

- Editing the source code or documentation of featured projects.
- Publishing private contact information.
- Claiming production readiness where a repository describes itself as a prototype.
- Pinning repositories through GitHub account settings.
- Inventing education credentials or additional language proficiency not supplied
  by Jared.
