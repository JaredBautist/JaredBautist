## About me

I'm a full-stack engineer based in Colombia who enjoys owning features end to end:
defining the contract, designing the database, implementing the backend, building the
frontend, and delivering the result. My work and projects span healthcare automation,
enterprise management platforms, cloud infrastructure, data engineering, and
AI-assisted developer tooling.

I care about **clean architecture**, explicit contracts, automated testing, and
software that remains understandable after the first release. One of my proudest
achievements is finishing **Top 2 in the PrimeWorks AI Engineering Technical
Challenge**, where I applied Specification-Driven Development and modern AI workflows
to a production-oriented engineering problem.

### 1. [AXOLOT](https://github.com/JaredBautist/AXOLOT)

[![GitHub stars](https://img.shields.io/github/stars/JaredBautist/AXOLOT?style=flat-square&logo=github&label=Stars)](https://github.com/JaredBautist/AXOLOT/stargazers)

A terminal-first AI coding assistant published on npm. AXOLOT supports multiple AI

**Engineering focus:** provider adapters, CLI/TUI design, extensible skills, session
persistence, cross-platform distribution, and developer experience.

### 2. [Coworking Management Platform](https://github.com/JaredBautist/Coworking-Management-Platform)

[![Live demo](https://img.shields.io/badge/Live_demo-Open-16A34A?style=flat-square&logo=vercel&logoColor=white)](https://coworking-management-platform.vercel.app)
[![TypeScript](https://img.shields.io/badge/TypeScript-3178C6?style=flat-square&logo=typescript&logoColor=white)](https://github.com/JaredBautist/Coworking-Management-Platform)
[![PostgreSQL](https://img.shields.io/badge/PostgreSQL-4169E1?style=flat-square&logo=postgresql&logoColor=white)](https://github.com/JaredBautist/Coworking-Management-Platform)

A 72-hour multi-tenant SaaS prototype for coordinating shared workspaces across
companies. It includes workspace reservations, real-time availability, role-based
access, reporting, CSV export, internationalization, and responsive dark mode.
Booking conflicts are protected in PostgreSQL with an exclusion constraint, while
Row Level Security enforces tenant boundaries.

**Stack:** React 19, TypeScript, Vite, Tailwind CSS, TanStack Query, Supabase, and
PostgreSQL.

### 3. [MIPRES Delivery Optimization Platform](https://github.com/JaredBautist/OPTIMIZACION-DE-ENTREGA-Y-ENVIO-A-EL-MIPRES)

[![Healthcare](https://img.shields.io/badge/Domain-Healthcare-DC2626?style=flat-square)](https://github.com/JaredBautist/OPTIMIZACION-DE-ENTREGA-Y-ENVIO-A-EL-MIPRES)
[![NestJS](https://img.shields.io/badge/NestJS-E0234E?style=flat-square&logo=nestjs&logoColor=white)](https://github.com/JaredBautist/OPTIMIZACION-DE-ENTREGA-Y-ENVIO-A-EL-MIPRES)
[![React](https://img.shields.io/badge/React-20232A?style=flat-square&logo=react&logoColor=61DAFB)](https://github.com/JaredBautist/OPTIMIZACION-DE-ENTREGA-Y-ENVIO-A-EL-MIPRES)

A healthcare operations platform that streamlines delivery, reporting, and invoicing
workflows against Colombia's official MIPRES services. The backend centralizes API
access, boundary validation, rate limiting, JWT handling, and operational logging; the
responsive frontend provides guided forms and response tracking for daily work.

**Stack:** NestJS, React, Vite, Bootstrap, Axios, JWT, and the official MIPRES APIs.
